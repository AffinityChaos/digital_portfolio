About Me

Transforming Ideas Into Impactful Web Experiences

I'm a Front-End Developer at RanTechnology, building production websites for clients across real estate, interior design, and EV sectors.

My stack is HTML, CSS, Tailwind CSS, vanilla JavaScript, and PHP, with GSAP and Swiper.js for animation and interactive UI. Recent work includes a wardrobe/kitchen configurator with real-time collection switching, a physics-based interactive team page using Matter.js, a filterable project gallery for a real estate developer, and SMTP-integrated contact forms for EV brands.

I care about getting the details right — clean responsive layouts, animations that don't feel bolted on, and debugging the small things (scope errors, duplicate event listeners, layout breakages) that make a site actually feel solid in production.

Currently deepening my JavaScript fundamentals and learning React to build more complex, interactive web applications.
